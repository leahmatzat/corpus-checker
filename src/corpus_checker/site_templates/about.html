How to read a verdict

Every verdict is for one model, one training stage, one dataset — never for a model as a whole. There is no overall score, grade or rank anywhere on this site.

Self-eval vs. catalog. A finding is {{ m.self_eval_marker() }} when the model's own paper evaluated on that dataset. Every other dataset in the shared catalog is checked too and shown as a catalog finding — cross-model reuse is exactly what a catalog finding can surface.

{{ m.draft_badge() }} means the entry has not yet been signed off by a verifier listed in verifiers.yaml. Draft entries can still be inspected — every source and finding is shown exactly as recorded — but no person has confirmed the claims yet.

Disputed entries. An entry is never silently removed. If an author or reader disputes a finding, the dispute statement is recorded and shown prominently on the model's page — the entry stays visible alongside it.
